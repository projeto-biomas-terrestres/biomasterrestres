> Uma aplicação web interativa e responsiva desenvolvida para explorar ecossistemas globais através de interfaces dinâmicas, modernas e intuitivas.

---

## ✨ Funcionalidades

- 📱 **100% Responsivo:** Otimizado para telas de dispositivos móveis, tablets e desktops.
- ⚡ **Componentes Dinâmicos:** Uso de modais customizados sem obstruir a leitura principal.
- 🎨 **UI Exclusiva:** Animações e transições suaves sem o uso de cores fluorescentes, priorizando uma leitura confortável.
- 🗂️ **Conteúdo Estruturado:** Informações divididas em blocos de fácil absorção (Flora & Fauna, Adaptações e Importância Global).

---

## 🛠️ Tecnologias Utilizadas

* **HTML5:** Estruturação semântica do conteúdo.
* **CSS3:** Variáveis nativas, Flexbox, CSS Grid e animações personalizadas.
* **Bootstrap 5:** Sistema de grids responsivos e infraestrutura de modais.
* **Google Fonts:** Tipografias selecionadas (*Outfit*, *Playfair Display* e *Plus Jakarta Sans*).
